# 蕾米埃尔桌宠 Remielle Desktop Pet

绝区零（Zenless Zone Zero）角色 **蕾米埃尔** 的 Windows 桌面宠物。  
轻量、免安装，带简单待办（Todo）功能。

## 功能

- 桌面宠物展示（可拖动）
- 简单待办：添加、完成、归档
- 基础提醒（可选）
- 解压即用

## 系统要求

- Windows 10 / 11（64 位）
- 无需安装，解压后直接运行

## 下载

前往 [Releases](../../releases) 下载最新版本：

- `remielle-windows-x64-v1.0.1.rar`

## 使用方法

1. 下载并解压.rar
2. 运行主程序`remielle.exe`
3. 桌面出现宠物后即可拖动、使用待办功能
